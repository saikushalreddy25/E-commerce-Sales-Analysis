# E-commerce-Sales-Analysis
This project contains an interactive dashboard created using Microsoft Power BI Desktop to analyze and visualize data from a given dataset. The dashboard provides insights through charts, graphs, and key performance indicators (KPIs), helping users understand trends, patterns, and overall performance.
